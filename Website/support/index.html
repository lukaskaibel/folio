Common questions

How do I get Notebook?

For now you build it yourself: a Mac with Apple silicon and macOS 27, Xcode 27, and about five minutes. The steps are in the README, and a local build needs no Apple developer account. The Mac App Store comes later.

Where are my notes kept?

Where they already are. Notebook shows the folders you add, iCloud Drive or any other, and reads and writes the Markdown files in them in place. A note's title is its file name. Pictures and files you add to a note go into a hidden .assets folder next to it, and that is all Notebook adds.

Can I keep using Obsidian, iA Writer or GitHub?

Yes. Notes are ordinary Markdown, so other apps read them just the same, and [[links]] find the note by its name as Obsidian does: one in the same folder first, then the one with the shortest path.

What if a note changes on another Mac?

Notebook watches the open note. If it changed somewhere else and you haven't typed, it reloads quietly. If both sides changed, it merges the two line by line and never writes over a change it hasn't seen. Only when both changed the same lines does it ask: keep this version, use the other one, or keep both.

Is there a version for iPhone and iPad?

Not yet. iPhone and iPad versions are planned, from the same project, together with quick capture from a widget and the share menu.

Does Notebook collect anything?

No. It has no server, no accounts, no analytics and no advertising, and it never connects to the internet. The details are in the privacy policy.
